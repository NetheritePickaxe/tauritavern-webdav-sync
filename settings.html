WebDAV Sync
Sync your TauriTavern data directory to any WebDAV server (r2-webdav, Nextcloud, ownCloud, ...).
Push exports your data to a zip archive, then uploads it to the WebDAV server. Because the exported archive is written to your Downloads folder, select that file in the picker to finish the upload. Warning: pulling will merge into your current local data directory (same-path files will be overwritten).
